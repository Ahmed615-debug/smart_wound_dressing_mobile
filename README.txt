SMART WOUND DRESSING — MOBILE POLISH V3

Static academic demonstration prototype.
- Open index.html locally or deploy the folder contents using GitHub Pages / Netlify.
- No Node.js or backend required.
- Sample readings are simulated, not connected to real sensors and not for medical decisions.
- LocalStorage saves demo account/settings/history/alerts in the current browser on this device.
- For GitHub Pages, upload index.html to the repository root, then Settings > Pages > Deploy from a branch > main > /(root).
